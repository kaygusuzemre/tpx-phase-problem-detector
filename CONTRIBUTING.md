# Contributing

Thanks for helping make stereo diagnostics clearer and more trustworthy.

## Good contributions

- A minimal reproduction for a decoding or browser-compatibility issue
- A redistributable stereo fixture with a documented expected measurement
- A correction to the measurement method with references or test evidence
- Accessibility, mobile layout or plain-language interpretation improvements

## Development

1. Run `npm test`.
2. Start the local site with `npm run serve`.
3. Keep audio analysis local; do not add uploads or analytics without an explicit privacy review.
4. Add or update a test when changing measurement behavior.

Open an issue before a large behavior or dependency change so the measurement goal stays narrow and verifiable.
